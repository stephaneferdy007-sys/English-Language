# English Mastery — Android

Application Android hors ligne basée sur les modules HTML English Mastery fournis.

## Fonctionnalités
- 11 modules (0 à 10) intégrés dans l'application.
- Interface Android native pour l'accueil et la navigation.
- Lecture du contenu en WebView, sans connexion Internet.
- Progression locale : chaque module peut être marqué comme terminé.
- Test interactif et JavaScript des modules conservés.
- Écran portrait optimisé pour smartphone.

## Ouvrir dans Android Studio
1. Décompresser le ZIP.
2. Ouvrir le dossier `EnglishMastery_Android` dans Android Studio.
3. Laisser Android Studio synchroniser Gradle.
4. Lancer sur un téléphone Android ou un émulateur.
5. Pour produire un APK : Build > Build APK(s).
